# 公共学习工作流

这是从原个人学习手册抽出的通用使用方法；个人课程材料、进度、考试计划和演示记录未公开。

1. 先选择课程工作区，再打开阅读、聊天、知识库或笔记，避免把不同科目混在一起。
2. 单份资料按页阅读；临时题目用附件；跨文件问题再选择对应知识库。
3. 中文讲解保留英文术语和原资料符号，要求引用物理页码，并区分原文内容与补充解释。
4. 先自己复述或答题，再获取提示与反馈；将结论和未掌握点保存为自己的笔记。
5. 复习时再次独立作答，不把演示答案视为个人掌握记录。

可复用请求：

```text
请依据当前资料的指定页讲解这个概念。
用中文说明直觉，保留英文术语与原符号，给出准确页码。
先让我复述，再出一道英文检查题；等我回答后再反馈。
资料没有说明的部分请明确标为补充，不推测我的考试范围。
```

OCR 提取用于检索与辅助讲解，公式、上下标和手写内容应对照原图。PDF 转换保留静态页面，不保留原演示动画。桌面和 CLI 各自保存资料、聊天、批注及进度；不要把一处显示的状态当成另一处已经同步。
