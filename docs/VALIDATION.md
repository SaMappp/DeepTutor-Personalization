## 已知限制

所有补丁固定于 v1.7.1；升级会覆盖运行时或缓存。原生 OCR 依赖 Windows 锁机制、本机字体和额外模型配置；公式和手写识别未达到逐式校对标准。历史课程与部署脚本包含环境假设，需要自行配置，不能当成跨平台安装器。

公开版通用 API 工具与账号适配器的认证入口为发布时适配；本次只测试通用工具的本机逻辑，不声称已验证任何企业 API 或新的账号授权。服务条款、模型目录与账号权限可能变化。
