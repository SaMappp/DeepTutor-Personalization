# 完成后的 GitHub 同步

维护者于 2026-11-16 明确要求：以后有关 DeepTutor 的修改和优化，在确认完成后同步到 `SaMappp/DeepTutor-Personalization`。该授权持续适用于 DeepTutor 工作；普通同步无需再逐次请求确认。

1. 确认实际修改的实例、版本和组件，完成与改动相称的测试及必要的实际验收。失败、未验证和限制如实记录。
2. 使用明确文件清单导出完整源码，按当前官方基线重新生成对应补丁，更新 manifest、来源哈希、NOTICE、改动清单、时间线和验证记录。
3. 扫描公开副本与暂存差异。只同步可公开代码和整理记录；密钥、原聊天、学习资料、数据库、资料调查缓存、原始测试响应及私人备份留在本机。
4. 检查作者和提交者身份。新提交使用 GitHub 隐私邮箱；不得因为上传源码就顺带公开个人联系方式。
5. 拉取远端最新状态，合并本次改动并正常推送。不得无授权强推、覆盖他人的改动或改写历史。
6. 核对远端分支 SHA 和代表性文件，向维护者提供仓库/提交链接。无法上传时保留进度并说明原因，不能把本地提交称为完成同步。

验证命令和组件限制见 [复现与维护](REPRODUCING.md)；公开边界见 [PUBLICATION_SCOPE.md](PUBLICATION_SCOPE.md)。这是开发任务结束时执行的工作规则，不是定时任务或后台目录监听。
