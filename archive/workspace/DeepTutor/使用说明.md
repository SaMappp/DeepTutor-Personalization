# DeepTutor 使用说明

安装方式：官方 PyPI 完整版 1.7.1，使用本目录下独立的 `.venv`。

## 日常使用

- 双击 `Start-DeepTutor.cmd` 启动，后台运行。
- 打开 http://127.0.0.1:3782 使用网页。
- 双击 `Stop-DeepTutor.cmd` 停止服务。
- 首次使用或登录过期时，双击 `Login-Codex.cmd`，在浏览器中登录你现有的 ChatGPT 订阅账号。

界面和模型回答默认使用简体中文。当前先做通用配置，不导入课程材料、不建立知识库。

## 数据位置

本目录就是固定的 DEEPTUTOR_HOME。应用配置在 `data/user/settings/`，其他运行与学习数据也在 `data/` 下。订阅授权凭据由 DeepTutor 自己保管。不要公开分享整个 data 目录。

## CLI

在本目录打开 PowerShell：

```powershell
$env:DEEPTUTOR_HOME = (Get-Location).Path
$env:PYTHONUTF8 = '1'
& '.\.venv\Scripts\deeptutor.exe' --help
& '.\.venv\Scripts\deeptutor.exe' config show
& '.\.venv\Scripts\deeptutor.exe' doctor --format json
```

执行 CLI 聊天前，先停止网页版，避免同一运行目录中的会话执行冲突：

```powershell
& '.\.venv\Scripts\deeptutor.exe' stop
& '.\.venv\Scripts\deeptutor.exe' run chat '用中文解释什么是函数，并举一个简单例子。' --language zh --format json
```

## 双击启动行为

Start-DeepTutor.cmd 会先确认服务是否已运行；已运行时直接打开浏览器，避免重复启动造成端口冲突。未运行时会启动服务，并等待前后端均就绪后打开网页。成功后终端会自动关闭；失败时显示错误和日志位置，并保留窗口。

启动逻辑位于同目录的 start_deeptutor.py。已通过 Windows 文件关联启动验证：从完全停止到就绪成功；重复运行保持同一个后台管理进程，网页正常响应。
