# PDF 教材自动处理与导入工具

双击上一级目录中的 **PDF教材自动处理与导入.cmd**。

日常使用：

1. 先打开原来的 DeepTutor 桌面版。
2. 双击工具，点「添加 PDF…」，可一次选择多本。
3. 选择现有工作区和阅读组。默认连接桌面版；CLI / PyPI 是另一套独立数据，仅在你明确选择且它已经启动时连接。
4. 页码留空处理全书；也可输入 `1-10,15,20-25`。这里始终指从 PDF 第一页开始数的**物理页码**，与书内印刷页码可能不同。多本文件使用同一范围，超出某本页数会明确报错。
5. 点「开始处理并导入」。工具会检查页面，复用足够的正文文字层，仅对需要的扫描页做本地 OCR。全书可能需要十几分钟或更久，进度和错误会显示在窗口里。
6. 完成后点「打开阅读组」。已经打开旧的阅读页面时，刷新后选择新标签。

## 输出与续作

默认输出到：

`C:\Users\YOUR_NAME\Documents\ChatGPT\Academic learning\Course materials\PDF教材自动处理输出`

每本书使用独立子目录，内含可搜索 PDF、处理记录、中文说明和 DeepTutor 导入记录。部分处理的文件名带 `OCR部分_第…页`，说明和 PDF 元数据也标明已完成的物理页码范围；其他页保持原样，不会删页。以后选择原件处理全书，会自动复用已经完成的页。

原件不覆盖。已有输出与内容哈希匹配时直接复用；输出发生变化时另存新版本。新书、不同页码、不同 OCR 模型或关键参数的缓存不会混用。缓存完整性也会检查。

「完成当前页后暂停」会让已经开始的少量页面先完成并保存缓存。再次启动、选择同一原件和范围即可续作。异常失败的页会记录在 `cache` 中对应的运行记录和窗口日志里；再次运行仅补未完成或失败页。不要在处理中删除 `cache`。

相同 PDF 内容已经存在于所选 DeepTutor 工作区时，工具验证其完整内容哈希并直接复用；已经加入阅读组的材料不会重复添加。原教材、原材料的阅读记录、批注和书签不会被删除或改写。新 OCR 版在原教材也已导入时沿用它的阅读位置。

## 识别质量与边界

教材只在本机 OCR，不上传外部 OCR 服务，不调用付费模型。工具不升级 DeepTutor 核心，不改变 GPT-6.1-Sol/high、模型计费来源、工作区配置或开机启动。

正文量、长文本行、文字分布、大图覆盖率和重复水印用于判断是否需要 OCR；页码、少量笔记或图片标记不算完整正文。这是保守启发式，极特殊版式仍可能判断不准。可通过页级记录查看判定原因；成功但内容不理想的识别结果不会因重复运行而自动改善，不能将其视为公式已校对。

公式、上下标、分式、多行公式、希腊字母与手写批注存在误识别。可搜索文字用于定位和辅助理解；抄题、计算和引用公式以保留的原图为准。当前教材已观察到 `x/α`、`v/u` 等混淆，不能宣称公式完全正确。

加密、损坏或无法直接打开的 PDF 会报错。纯插图、空白扫描页可能没有可识别文字，会列入处理记录中的 `ocr_no_text_pages` 供检查。没有识别出文字的页不会被虚称为已获得正文。

工具依赖现有 `DeepTutor\.venv` 的 Python/PyMuPDF/ONNX Runtime，并从旁边的 `ocr\runtime` 加载独立的中文 OCR 包与模型；不会把这些新包装进 DeepTutor 的虚拟环境。不要单独移动或删除这些目录。安装更新或移动环境后如启动失败，查看 `logs` 或从终端运行 `gui.py` 获取错误；工具不会自动重新配置 DeepTutor。

## 可选命令行

使用现有 Python 运行同目录 `cli.py --help`。省略 `--workspace`/`--collection` 时只生成文件；两者一起指定时导入已有阅读组。`--list-targets` 只列出已有工作区与阅读组。工具不会启动未运行的服务。
