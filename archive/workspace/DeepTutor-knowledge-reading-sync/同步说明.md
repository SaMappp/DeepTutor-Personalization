# 知识中心与沉浸式阅读同步

已在现有桌面版和 CLI/PyPI 1.7.1 中补上本地文档同步。原来知识库索引与阅读资料分开保存，上传只进入知识库，所以不会自动出现在阅读合集。

## 以后怎么用

1. 进入对应课程工作区，在 **资料 → 知识中心** 新建知识库并上传文件，或向已有知识库追加文件。
2. 打开同一工作区的 **学习 → 沉浸式阅读**。文档会自动加入对应阅读合集，不需要再导入一次。
3. 能明确匹配已有合集时直接追加到原合集；否则建立 **知识中心 · 知识库名称** 的合集。
4. 若阅读页面已经开着，切回沉浸式阅读或刷新一次即可重新读取列表。同步失败的本地文件也会在后续进入阅读时重试。

本次已补齐：Python 的 Lecture 5–6 Homework 加入原“英文原版 PDF 课件 · Computer Programming”；Calculus 知识中心的4份原始PDF加入“Calculus textbooks”。原来的OCR可搜索阅读版、批注、书签、进度和对话继续保留。

## 同步规则

- 同一内容按哈希去重，已存在的阅读材料直接复用。
- 同名文件内容改变时，保留旧阅读副本并加入新内容，避免冲掉原批注和进度。
- 知识库删除文件不会自动删除阅读资料或历史记录。
- 桌面版和 CLI/PyPI 继续使用各自的数据目录，各自同步；不会跨实例合并资料。文档归入知识库所属工作区，不串入当前浏览的其他课程。
- 同步不重建知识库索引，也不发起模型、付费API、全书OCR或图片描述请求。扫描PDF继续使用已有的按页OCR和缓存。
- PDF 保留原页显示；其他格式沿用阅读器原有的格式支持。PPT若需要完整幻灯片外观，继续先用已有“PPT转PDF.cmd”转换，再将PDF加入知识中心。
- 当前桥接本地保存、阅读器支持且不超过其200MB上限的文档；没有本地原文件的远程知识服务不会自动下载。损坏文件、格式不支持等错误会记录在同步状态中，不撤销已成功的知识库上传。
